# HanafubukiResourceWorld

**Мир ресурсов со сбросом по расписанию — чтобы основной мир не превращался в швейцарский сыр.**

## Возможности

- 🌍 **Отдельный мир ресурсов**: плагин сам создаёт и загружает его, Multiverse не нужен.
- 🔄 **Сброс по расписанию**: раз в N дней мир стирается и генерируется с новым сидом.
- ⏰ **Личные напоминания**: за N дней до сброса каждый игрок при входе видит, сколько осталось. В любой момент можно проверить через `/rwtime`.
- 🛏️ **Кровать там не ставит точку возрождения**, поэтому `/home` через кровать остаётся в основном мире.
- 🚫 **Порталы в Незер и Энд в мире ресурсов отключены**: никаких коротких путей в основной Незер.
- 🌀 **Необязательный портал**: отмечаешь область (например, арку на спавне), игроки заходят и переносятся.
- 🎯 **Безопасная случайная точка**: чанки грузятся асинхронно, вода, лава и листва отсекаются.
- 🧱 **Граница мира** и необязательная прегенерация **Chunky** после каждого сброса.
- 🌐 Английский по умолчанию, русский встроен, можно добавить свой язык.

## Как туда попасть

- **Портал**: включается в конфиге, область задаётся в игре (см. ниже).
- **Команда**: на Hanafubuki это `/resources` из [hanafubuki-core-plugin](https://github.com/Hanafubuki-minecraft/hanafubuki-core-plugin) с тем же отсчётом, что у `/spawn` и `/home`. Подойдёт и любой другой плагин телепортов, который умеет отправлять в мир `resources`.

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/rwtime` | Сколько осталось до сброса | `hanafubuki.rw.info` (все) |
| `/rwadmin info` | Мир, дата сброса, состояние портала | `hanafubuki.rw.admin` (op) |
| `/rwadmin reset` | Сбросить сейчас (с подтверждением) | `hanafubuki.rw.admin` |
| `/rwadmin portal pos1 \| pos2 \| save \| enable \| disable \| clear` | Настроить область портала | `hanafubuki.rw.admin` |
| `/rwadmin language [код]` | Показать или сменить язык | `hanafubuki.rw.admin` |
| `/rwadmin reload` | Перезагрузить конфиг и языки | `hanafubuki.rw.admin` |

## Настройка портала

1. Построй арку на спавне из любых блоков.
2. Посмотри на один угол внутри и выполни `/rwadmin portal pos1`, затем на противоположный угол — `/rwadmin portal pos2`.
3. Выполни `/rwadmin portal save`: область сохранится, и портал сразу включится. Выключить или включить обратно: `/rwadmin portal disable` / `enable`.

Конфиг с комментариями создаётся при первом запуске (`plugins/HanafubukiResourceWorld/config.yml`).

> При сбросе мир выгружается, папка удаляется, генерируется новый мир. Сервер может подвиснуть на несколько секунд. Если дата сброса прошла, пока сервер был выключен, сброс произойдёт при следующем запуске, до входа игроков.

## Релизы

Поднимаешь `version` в [`gradle.properties`](gradle.properties) и пушишь в `main`, GitHub Actions собирает jar и публикует релиз `v<версия>`.
